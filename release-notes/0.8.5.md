- 查询源码、GitHub 和当前事实时，群成员可进行新的受限只读查证，并在取得真实读取回执后给出带来源的结论。普通讨论继续不提供执行工具；本机原生 Agent 的深入执行仍走原有分工任务。

- 验证 `git ls-remote` 查询保存结果及普通报告写入可复用已有目录常规授权；审批文案使用“长期允许此命令”，不再添加多余的高危标签。
