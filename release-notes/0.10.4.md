# KTeam 0.10.4

- 小 K 在私聊展示简报、日程变更和会议邀请卡片。会议卡片列出通知中明确的时间、地点和参会状态，可展开通知详情并起草日历核对请求。
- 小 K 检测到所选云之家来源需要重新登录时，会在私聊提醒。同一次失效只提醒一次，使用同一账号续登会保留已选来源。暂时不可用的来源恢复后可补发满足条件的简报。
- 生成的文件以独立消息发到原会话，可在桌面侧栏打开预览并保存原文件。macOS 支持一次粘贴多个目录路径。
- 会话顶部合并 Agent 和模型设置。引用会话入口移到输入栏，消息处理进度收进会话详情。
- 工具审批展示触发依据和执行回执。混合终端命令使用一次审批，桌面和配对手机会标明涉及的操作。分析任务使用完观察轮次后，可以根据已保留的查证结果提交总结。

桌面下载提供 macOS Apple 芯片版和 Windows x64 安装版、便携版。
