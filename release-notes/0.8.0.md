# KTeam 0.8.0

本版集中改进群成员并行回应、执行可靠性和交付结果核验。

- 群内独立成员默认并行回应，明确依赖前序结果时串行；私聊阶段与负责人最终复核继续保留。
- 按可信传输记录真实请求尝试，SDK重试与辅助请求分别计量，持久预留避免重复扣同一次尝试。
- 内置执行器保留冻结输入与来源资料，压缩后可恢复原要求；未获保留证明的适配器不冒充完整增量连续性。
- HTML私有候选验证后再发布，最终成功答复前核对产物/邮件/effect回执；邮件unknown不自动重发，沿用原批准。
- HTML/Markdown产物可在KTeam内打开，持久入口不受最近工具记录窗口截断影响，继续校验会话/主机/文件摘要。
- 修复Windows产物回执的JSON路径转义，最终结果正确指向已发布文件。
- Reward Memory基于明确人类验收与真实交付证据，可过期、撤销，不改变权限。

结构校验不等于主观业务验收。真实Mac睡眠唤醒、全部第三方SDK bridge和优化路线图的其他候选项不因本版发布而被宣称完成。

安装包由GitHub Actions在Mac/Windows构建、跨平台检查及产物校验全部通过后自动发布：

- macOS Apple Silicon：Developer ID签名、公证并装订的dmg与自动更新zip。
- Windows x64：NSIS安装版与便携版；当前未签名。NSIS附带自动更新元数据，便携版手动更新。
- SHA256SUMS用于校验安装包与更新元数据。仅使用KTeam官方GitHub Releases更新源。
