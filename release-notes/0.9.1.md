# KTeam 0.9.1

- 复制访达中的目录后，粘贴为输入框中的目录路径，避免生成无法读取的目录附件。普通文件和图片仍遵守原有上传权限。
- 模型认证失败、限流、服务或连接异常直接显示在会话中，明确成员、模型、原因和 HTTP 状态，并提供模型设置和失败详情入口。
- 只读调研方案不会执行模型附带的开发阶段；未执行工具的最新群聊分派格式失败会自动恢复一次，旧执行记录保持不变。
- 点名成员的回复范围在恢复时保持不变；分工方案失败后会进行一次受限纠错，已完成只读取证的成员可依据保留的回执整理答复，不重做工具调用。
- 群内等待卡片展示受阻成员的具体原因，以及模型调整、私聊确认入口；模型执行模式与工具审批不兼容时明确提示，不再只显示内部错误。
- 群聊选择发言成员失败时也会显示提示，不再只留下没有回复的群聊。历史失败不会覆盖新请求和成功重试的状态。

- 保留 K3 模型并支持工具审批后接续、重启恢复；用有界的公开历史和实际工具回执恢复上下文，不落盘或重放私有推理，不重复执行已完成工具。

- 群工作超时后继续时，旧分工阶段仅用于核对，不再作为新任务的有效交接或自动重做；当前任务自己创建的正常分工仍会按阶段接续。

- K3 多轮工具调用从原会话生成有界公开上下文，原回执完整保留；模型缺少必需字段或只返回工具请求文本时明确提示，不再当作完成答复。旧的异常答复可在核对原始投递来源后，显式接续新执行，旧消息和回执保持不变。

macOS 安装包与 Windows 安装版支持自动更新；Windows 便携版需手动下载。未签名的本地开发包需先安装一次正式签名版，之后继续使用正常更新流程。

- 分阶段群工作分别计算各阶段及负责人复核的期限；未指定较短等待时，成员交接遵守原任务期限，不再默认 30 分钟停工。成员单次执行仍限一小时，明确指定的短期限、暂停、权限与来源核验继续生效，旧任务合同不会被静默延长。
