# KTeam 0.9.3

- 群聊分工未通过校验时，重试会收到具体的失败字段。连续失败会在群内说明尚未派发，并保留「继续这项工作」。接续依据原消息和已保存的回执重新分工。
- 已授权目录中的非交互 `timeout git ls-remote` 查询复用目录授权。缺少授权时，可长期允许实际工作目录，包括给当前群成员授权。修改远端、推送和自定义上传程序仍需单独确认。
- 筛选测试日志的内联 awk 正则不会再出现在待授权目录或操作路径里。文件参数仍按实际路径检查。
- 审批卡优先展示授权范围和关键修改目标，命令、任务号和技术详情按需展开。「管理此成员已有授权」移到卡片左下角。
- 混合检查和删除的申请提示先拆分，并提供明确的拒绝操作。确认或拒绝完成后，已处理的卡片会收起。

支持 macOS Apple 芯片（arm64）和 Windows（x64）。Mac 与 Windows 安装版可自动更新，便携版手动下载。
