# KTeam 0.9.4

- 群组负责人核验时遇到模型断线，旧执行已停止且成员回执已返回时，可自动接续一次。已返回的阶段回执会保留，交付后继续处理排队消息。
- 恢复群聊时，未开始的任务及暂停期间收到的消息可继续执行。人员、权限或其他设置发生变化时，仍按原规则重新核对。
- 负责人依据可复现的验收结果处理分歧。失败项交回实际负责人修复，质量复验后再核对提交回执。
- 修复 macOS 深色模式下 @ 成员菜单白底浅字的问题。背景、边框和选中高亮跟随当前主题。

支持 macOS Apple 芯片（arm64）和 Windows（x64）。Mac 与 Windows 安装版可自动更新，便携版手动下载。
