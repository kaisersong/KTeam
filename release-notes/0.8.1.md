修复 Windows 首次使用及更新失败反馈。

- Windows 状态锁会核对进程启动时间，避免旧 PID 被其他程序复用后永久阻断内置协作服务；无法确认身份时继续保留锁。
- 从小K主动导入模型时，外部配置可以有其他账号的只读权限，仍拒绝其他账号可写的配置。KTeam 自身凭据继续使用严格权限检查，外部配置不会被修改。
- 首次使用先等待本机服务就绪，再进入模型配置；启动失败显示恢复入口，连接恢复后清除过期服务提示。
- 修复更新包签名验证失败时仍显示重启按钮的问题，提供清晰原因与官方下载安装入口。

本地 ad-hoc 签名的 Mac 包切换至正式版本，需要覆盖安装一次官方签名版。请保持官方包签名，后续通过自动更新升级。
