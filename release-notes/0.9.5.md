# KTeam 0.9.5

- 群顶部显示成员待确认、受阻和已交付的状态，可定位原消息、对应派单、成员回执及授权卡。明确要求另行接收的群内工作简报可路由到用户私聊。
- 审批卡显示可定位的触发命令段。批准、拒绝、取消和过期保留独立回执，用户可以核对对应的工作记录。
- @ 成员候选支持明暗主题、键盘选择和列表内滚动。输入法选字期间保留输入，从访达粘贴目录时将路径放入输入框。
- 增加当前工作区内普通 Git 仓库的引用、提交、分支包含关系和远端抓取规则查询。查询沿用现有范围限制与显式拒绝。
- 修复手机连接路由、配对身份核对和权限撤销，手机审批展示使用脱敏数据，并与桌面的中断工作状态对齐。

提供 macOS Apple 芯片（arm64）和 Windows（x64）桌面安装包。Mac 与 Windows 安装版可自动更新，Windows 便携版手动下载。
