# KTeam 0.10.0

## 小 K 助理的每日工作

- 在小 K 私聊中用对话制定和调整计划。确认后可按早、中、晚生成简报，也可临时检查一次、跳过当期简报或暂停。
- 在「今日」查看待处理事项、日程冲突、简报和各来源的检查范围。可按需连接邮箱、云之家消息、日历、知识库和公开资讯，并打开有权限的原文。
- 可为适合回复的事项准备可编辑的回复草稿，或将事项带入会话草稿。发送由用户决定。
- 已配对的手机共用桌面宿主保存的计划，支持在对话中确认和修改计划，以及查看「今日」。

## 执行与协作

- KTeam 使用已核验的 Codex CLI 路径启动本机 Agent。
- 群聊对不符合预期格式的模型回复单独尝试恢复，保留其他成员的回复。

## 安装

GitHub Release 提供 macOS 和 Windows 安装包。iOS 测试版通过 TestFlight 分发。
