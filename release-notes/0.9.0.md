# KTeam 0.9.0

- 整合移动端配对、持久历史、产物查看和导航，修复连接恢复、过期请求取消及远程连接发现。
- 共享纪要支持从用户消息选择真实来源，区分人工输入和方案建群来源；不回填虚构历史。
- 审批卡解释确认原因，保留目录长期授权和配对手机的一次性审批边界。
- 同一文件连续保存只展示最新入口；兼容主机网络名变化，并核验安装身份与文件内容。
- 更新检查遇到临时网络错误后自动退避重试；更新仍经签名和完整性校验，下载和重启由用户决定。
- 整合本地 Agent 接入及公共项目文档改动，保留当前进程清理和跨平台保护。

费用估算、金额预算和逐产物验收等后续能力未在此版本宣称交付。

macOS Apple Silicon 提供签名公证的 dmg 和自动更新 zip；Windows x64 提供 NSIS 安装包和便携版。全部平台构建及校验通过后由 GitHub Actions 自动公开发布。
