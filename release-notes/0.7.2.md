## KTeam 0.7.2

### 主要更新

- 语音输入支持豆包、千问 ASR，提供麦克风入口、录音状态与识别文字编辑。
- 群聊支持相关成员公开回应、私聊分工执行、结果回传和负责人复核；支持添加、移除群成员。
- 新消息可改向或排队接续原工作；修复持续交接、审批恢复与执行租约过短导致的中断。
- 已授权目录复用常规脚本、解释器管道、Shell eval 和 SSH/SCP/SFTP 权限，避免仅因命令形式反复确认；实际危险操作保留单独确认。
- 修复图片预览和已解决回执残留；自动加载历史消息，支持一键回到最新。
- 默认启用分析卡片与云之家富文本准备；实际外发仍需明确要求与现有审批。
- 提供近期取消、过期审批的可查询记录；用户的成果确认和验收反馈会获得相关成员回执，不再被当成无需回应而丢弃。
- 同步 AIMP 3.2 正文及配套附件；保留实验性实现边界，未宣称完成标准握手、Templates、FastJoin 或 Core-L2 认证。

### 下载与更新

- macOS Apple 芯片：DMG 安装包、ZIP 自动更新包；Developer ID 签名并经 Apple 公证。
- Windows x64：NSIS 安装包支持自动更新，便携版手动更新；Windows 包尚未签名。
- 更新源仅使用 KTeam 自己的 GitHub Releases。校验文件见 `SHA256SUMS`。
- 当前不提供 Intel Mac 或 Linux 安装包。
