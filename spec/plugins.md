# KTeam 桌面插件清单

在设置的「插件」页粘贴 JSON，预览命令和草稿后确认安装，再启用插件。在桌面会话输入 `/plugin`，选择一条命令即可填入消息草稿。草稿可编辑，发送使用原会话的正常发送流程。

```json
{
  "manifestVersion": 1,
  "id": "review-kit",
  "name": "审阅工具",
  "version": "1.0.0",
  "description": "为常用的材料评审准备草稿。",
  "contributes": {
    "commands": [
      {
        "id": "review",
        "title": "审阅材料",
        "draft": "请审阅我提供的材料，列出主要风险、证据缺口和待决定事项。"
      }
    ]
  }
}
```

- 插件和命令 ID 使用小写英文字母开头，由小写字母、数字及连字符组成，长度最多 64。命令 ID 在同一个插件内唯一。
- 版本使用三个数字段。更换已安装的插件时使用同一个插件 ID 和更高版本。新版本安装后需要重新启用。
- 每个清单可定义 1–16 条命令。草稿最多 4096 字符，使用普通文本，首字符须为斜杠以外的字符。最多安装 32 个插件，清单总大小最多 512 KiB。
- 清单版本 1 的贡献点为 `contributes.commands`，支持上述字段。清单作为数据存入本机，调用时只向当前用户的桌面草稿提供文本。
